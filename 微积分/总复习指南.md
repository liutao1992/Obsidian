## 2. 通用复习原则

1. **先理解“为什么”，再背公式。** 每一章先问自己：它在解决什么问题？
2. **极限中永远记住：$h \to 0$ 不是 $h = 0$。** 所以在化简前不能代入。
3. **看到 $\frac{0}{0}$ 不要停，这是开始变形的信号。** 常用四大工具：通分、因式分解、约分、有理化。
4. **连续 = 图像能“一笔画”；可导 = 图像不仅连续，还要“光滑”没有尖角。**
5. **可导必连续，连续不一定可导。** 经典反例：$f(x) = |x|$ 在 $x = 0$ 处。

## 3. 各章节核心考点

### 3.1 代数变形基础

**核心目标**：处理极限/导数定义中常见的 $\frac{0}{0}$、根号、分式化简。

#### 必背公式

- 通分：$\frac{A}{B} \pm \frac{C}{D} = \frac{AD \pm BC}{BD}$
- 平方差：$a^2 - b^2 = (a - b)(a + b)$
- 共轭（有理化）：$(\sqrt{a} - \sqrt{b})(\sqrt{a} + \sqrt{b}) = a - b$
- 导数定义：$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$

#### 必会题型

- 用定义求 $\frac{1}{x}$ 的导数：先通分，再约去 $h$，得到 $-\frac{1}{x^2}$。
- 用定义求 $\sqrt{x}$ 的导数：分子有理化，得到 $\frac{1}{2\sqrt{x}}$。
- 用定义求 $x^n$ 的导数：展开后只保留含 $h$ 的一次项，得到 $nx^{n-1}$。
- 求 $\lim_{x \to a} \frac{x^2 - a^2}{x - a}$：因式分解约去 $(x - a)$，结果是 $2a$。

#### 常见错误

- 通分时只乘分母不乘分子。
- 减法通分后忘记给分子整体加括号。
- 在加法中乱约分：$\frac{a + c}{b + c} \neq \frac{a}{b}$。
- 把 $h \to 0$ 直接当成 $h = 0$ 代入。
- 认为 $\frac{0}{0} = 0$ 或 $1$。

### 3.2 第一章：函数、图像和直线

#### 核心概念

- **函数**：每个有效输入 $x$ 对应唯一输出 $y$。判断图像是否为函数用 **垂线检验**。
- **上域 vs 值域**：上域是“安全声明的输出范围”，值域是实际输出的集合。复杂函数通常只说上域为 $\mathbb{R}$。
- **定义域禁区**：分母不为 0；偶次根号下非负；对数真数大于 0；$\tan$ 在 $\cos = 0$ 处无定义。
- **反函数**：原函数必须是“一一对应”（用 **水平线检验**）。反函数的定义域 = 原函数的值域；图像关于 $y = x$ 对称。
- **挽救不可逆函数**：如 $x^2$，限制定义域为 $x \geq 0$ 或 $x \leq 0$ 后可取反函数。

#### 直线必记

| 形式 | 方程 | 何时使用 |
|---|---|---|
| 斜截式 | $y = mx + b$ | 已知斜率和 $y$ 轴截距 |
| 点斜式 | $y - y_0 = m(x - x_0)$ | 已知斜率和一点 |
| 两点式 | $\frac{y - y_1}{x - x_1} = \frac{y_2 - y_1}{x_2 - x_1}$ | 已知两点 |
| 截距式 | $\frac{x}{a} + \frac{y}{b} = 1$ | 已知两轴截距 |
| 一般式 | $Ax + By + C = 0$ | 统一表达 |

- 平行：斜率相同，截距不同。
- 垂直：斜率乘积 $m_1 \cdot m_2 = -1$（水平线和竖直线互相垂直）。
- 竖直线 $x = a$ 没有斜率；水平线 $y = b$ 斜率为 0。

#### 常见错误

- 说“$f(x)$ 是函数”不严谨，$f$ 才是函数，$f(x)$ 是函数值。
- $y = x$ 和 $y = \frac{x^2}{x}$ 不是同一函数，因为定义域不同。
- 求反函数时不限制定义域，导致 $x^2$ 的反函数写成 $y = \pm\sqrt{x}$。
- 垂直情况漏掉“斜率不存在”的处理。

### 3.3 第二章：三角学回顾

#### 核心理解

三角函数不是边长，而是**比例**：

- $\sin\theta = \frac{\text{对边}}{\text{斜边}}$ — 垂直分量
- $\cos\theta = \frac{\text{邻边}}{\text{斜边}}$ — 水平分量
- $\tan\theta = \frac{\text{对边}}{\text{邻边}} = \text{斜率}$

#### 单位圆与任意角

- 单位圆上：$x = \cos\theta$，$y = \sin\theta$，$\tan\theta = \frac{y}{x}$。
- 弧度：$360^\circ = 2\pi$ 弧度；$\theta\,\text{rad} = \theta \cdot \frac{180^\circ}{\pi}$。
- 象限符号：一全正，二正弦，三正切，四余弦（即“全正弦余切”）。
- 特殊角：$30^\circ, 45^\circ, 60^\circ$ 对应 $\frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}$。

#### 常见错误

- $\tan 90^\circ$ 无定义（因为 $\cos 90^\circ = 0$）。
- 混淆角度制和弧度制代入公式。
- 在不同象限不判断符号直接套锐角值。

### 3.4 第三章：极限导论

#### 极限本质

- 极限问的是 $x$ 无限接近 $a$ 时，$f(x)$ 的趋势，不是 $f(a)$ 的值。
- 左极限：$x$ 从左边接近 $a$；右极限：$x$ 从右边接近 $a$。
- 极限存在 $\Longleftrightarrow$ 左极限 = 右极限 = 有限值。

#### 极限不存在的三种情况

1. **跳跃**：左极限 $\neq$ 右极限（如分段函数在分界点）。
2. **无穷**：函数值趋于 $\pm\infty$（如 $\frac{1}{x}$ 在 $x \to 0$ 时左右不同）。
3. **振荡**：函数在 $a$ 附近无限震荡（如 $\sin\frac{1}{x}$ 在 $x \to 0$）。

> 注意：$\infty$ 不是极限值，而是极限不存在的一种描述。

#### 在无穷远处的极限

- $x \to \infty$ 时，$\frac{1}{x} \to 0$；$\sin\frac{1}{x} \to 0$；$x^2 \to +\infty$；$\sin x$ 振荡不存在极限。
- 若 $\lim_{x \to \infty} f(x) = L$（有限），则 $y = L$ 是水平渐近线。

#### 常见错误

- 把极限值和函数值混为一谈。
- 看到 $\frac{1}{x}$ 在 $x \to 0$ 时直接说“极限不存在”但不分左右。
- 认为 $y = \sin\frac{1}{x}$ 在 $x \to 0$ 时极限为 0（实际振荡不存在）。

### 3.5 第四章：求解多项式的极限问题

#### 核心思想

多项式极限若直接代入得到 $\frac{0}{0}$，说明分子分母有公共因子 $(x - a)$，可以**因式分解后约分**。

#### 因式分解工具箱

1. **提取公因式**：$3x^2 + 6x = 3x(x + 2)$。
2. **公式法**：
   - $a^2 - b^2 = (a - b)(a + b)$
   - $a^2 \pm 2ab + b^2 = (a \pm b)^2$
   - $a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$
3. **十字相乘法**：对 $ax^2 + bx + c$ 找两个数，乘积为 $ac$，和为 $b$。

#### 典型例题

$$\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} (x + 2) = 4$$

> 约分的前提是 $x \neq 2$，但求极限时 $x$ 无限接近 2 却不等于 2，所以可以约。

#### 常见错误

- 分解不彻底：$x^4 - 1 = (x^2 - 1)(x^2 + 1)$ 还能继续分解。
- 约分后忘记标注“$x \neq a$”。

### 3.6 第五章：连续性和可导性

#### 连续性（“一笔画”）

函数 $f$ 在 $x = a$ 处连续，必须同时满足：

1. $f(a)$ 有定义（且有限）。
2. $\lim_{x \to a} f(x)$ 存在（且有限）。
3. $\lim_{x \to a} f(x) = f(a)$。

三种常见不连续类型：可去间断、跳跃间断、无穷间断。

#### 区间上的连续

- 开区间 $(a, b)$：内部每一点连续。
- 闭区间 $[a, b]$：内部连续，且左端点右连续、右端点左连续。

#### 哪些函数天然连续？

- 多项式、指数、对数（定义域内）、三角函数（无渐近线处）。
- 连续函数的和、差、积、复合仍连续；商在分母不为 0 处连续。

#### 介值定理（IVT）

若 $f$ 在 $[a, b]$ 上连续，且 $f(a)$ 与 $f(b)$ 符号相反，则存在 $c \in (a, b)$，使 $f(c) = 0$。

> 应用：证明方程有根、奇数次多项式必有实根。

#### 最大值最小值定理（EVT）

若 $f$ 在闭区间 $[a, b]$ 上连续，则 $f$ 在该区间上一定有最大值和最小值。

> 两个条件缺一不可：不连续或开区间都可能没有最值。

#### 导数定义（极限形式）

$$f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$

$$f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}$$

$$f'(x) = \lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x} = \frac{dy}{dx}$$

> $\frac{dy}{dx}$ 不是普通分数，而是极限比的简写。

#### 导数的几何意义

- 平均变化率 = 割线斜率。
- 瞬时变化率 = 切线斜率。
- 导函数 $f'(x)$ 给出每一点的切线斜率；$f'(a)$ 是某一点的数值。

#### 可导性判定

- 左导数和右导数都必须存在且**相等且有限**。
- 常见不可导情况：尖点（如 $|x|$ 在 0）、间断点、垂直切线、剧烈振荡。

#### 可导与连续的关系

- **可导 $\Rightarrow$ 连续**（光滑必一笔画）。
- **连续 $\not\Rightarrow$ 可导**（一笔画不一定光滑，$|x|$ 在 0 是反例）。
- 逆否命题：**不连续 $\Rightarrow$ 不可导**。

#### 高阶导数

- $f''(x)$ 是“导数的导数”，$\frac{d^2y}{dx^2}$。
- $f^{(n)}(x)$ 表示 $n$ 阶导；$f^{(0)}(x) = f(x)$。
- 注意：$f''(x) \neq [f'(x)]^2$；$\frac{d^2y}{dx^2} \neq \left(\frac{dy}{dx}\right)^2$。

#### 常见错误

- 判断连续性时只算极限，忘记比较函数值。
- 分段函数在分界点不分别算左右极限。
- 看到 $|x|$ 时忘记拆成左右讨论。
- 认为“连续所以可导”。
- 把 $f'(x)$ 和 $f'(a)$ 混淆。

### 3.7 第六章：求解微分问题

#### 用定义求导（基础）

套路：**代入 → 展开 → 化简 → 消 $h$ → 令 $h = 0$**。

重要结果：

- $(x^n)' = nx^{n-1}$
- $\left(\frac{1}{x}\right)' = -\frac{1}{x^2}$
- $(\sqrt{x})' = \frac{1}{2\sqrt{x}}$
- $(x^a)' = ax^{a-1}$

#### 求导法则（核心工具）

| 法则 | 公式 | 记忆提示 |
|---|---|---|
| 常数倍 | $(cf)' = cf'$ | 常数直接提出 |
| 和差 | $(f \pm g)' = f' \pm g'$ | 逐项求导 |
| 乘积 | $(fg)' = f'g + fg'$ | 轮流求导，不要写成 $f'g'$ |
| 商 | $\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$ | 分子“上导下不导减上不导下导”，分母平方 |
| 链式 | $\frac{d}{dx}f(g(x)) = f'(g(x)) \cdot g'(x)$ | 先对外层求导，再乘内层导数 |

#### 典型例题

- $(5x^3)' = 15x^2$
- $(3x^5 - 2x^2 + \sqrt{x})' = 15x^4 - 4x + \frac{1}{2\sqrt{x}}$
- $(x^2 \sin x)' = 2x\sin x + x^2\cos x$
- $((x^2 + 1)^{99})' = 198x(x^2 + 1)^{98}$

#### 切线方程

步骤：

1. 求 $f'(x)$，代入 $x_0$ 得斜率 $m = f'(x_0)$。
2. 求切点 $(x_0, f(x_0))$。
3. 用点斜式：$y - f(x_0) = f'(x_0)(x - x_0)$。

#### 速度与加速度

- 位置函数 $x(t)$ 的一阶导是速度 $v(t)$。
- 速度函数的二阶导是加速度 $a(t)$，也是位置的二阶导 $x''(t)$。

自由落体（以向上为正）：

- $a = -g$
- $v = -gt + u$
- $x = -\frac{1}{2}gt^2 + ut + h$

> 负号来自“向上为正”的约定；$g$ 是重力加速度大小。

#### 常见错误

- 链式法则只对外层求导，忘记乘内层导数。
- 商法则分子符号写反或分母忘记平方。
- 乘积法则误写成 $(fg)' = f'g'$。
- 求切线时把导数值当成切点 $y$ 坐标。
- 速度为负时误以为速度大小为负。
- 求最高点时错令 $a = 0$；应令 $v = 0$。

## 5. 易混淆概念对比表

| 概念 A | 概念 B | 核心区别 |
|---|---|---|
| $h \to 0$ | $h = 0$ | 趋近 vs 到达；趋近时可以约分，到达时不能 |
| 极限 | 函数值 | 极限是趋势，函数值是实际定义；二者可能不同 |
| 因式分解 | 约分 | 先分解出公共因子，再约分；加法中不能直接约 |
| $\frac{0}{0}$ | 结果 $= 0$ | $\frac{0}{0}$ 是信息不足信号，不是答案 |
| 上域 | 值域 | 上域是声明范围，值域是实际输出集合 |
| 连续 | 可导 | 连续是一笔画；可导还要求光滑无尖角 |
| $f'(x)$ | $f'(a)$ | 前者是导函数，后者是某一点的数值 |
| $f''(x)$ | $[f'(x)]^2$ | 二阶导是再求导，不是平方 |
| 割线 | 切线 | 割线过两点；切线是割线极限位置，只过一个点 |
| IVT | EVT | IVT 解决“有没有零点/中间值”；EVT 解决“有没有最值” |

## 6. 快速自测题（覆盖全书）

> 先遮住答案，自己做完再对照。不会的题目直接回查对应笔记。

### 基础概念

1. 函数 $f$ 在 $x = a$ 处连续，需要满足哪三个条件？
   - 答案：$f(a)$ 有定义；$\lim_{x \to a} f(x)$ 存在；两者相等。

2. 极限 $\lim_{x \to a} f(x)$ 存在的充要条件是什么？
   - 答案：左极限 = 右极限 = 有限值。

3. 可导与连续的关系是什么？请举一个连续但不可导的例子。
   - 答案：可导必连续，连续不一定可导；$f(x) = |x|$ 在 $x = 0$ 处。

4. 导数 $f'(x)$ 和 $f'(a)$ 有什么区别？
   - 答案：$f'(x)$ 是导函数（函数），$f'(a)$ 是 $x = a$ 处的导数值（数）。

### 计算练习

5. 求 $\lim_{x \to 3} \frac{x^2 - 9}{x - 3}$。
   - 答案：$6$。

6. 用导数定义求 $f(x) = \frac{1}{x}$ 的导数。
   - 答案：$f'(x) = -\frac{1}{x^2}$。

7. 求 $(x^2 \sin x)'$。
   - 答案：$2x\sin x + x^2\cos x$。

8. 求 $((x^2 + 1)^{99})'$。
   - 答案：$198x(x^2 + 1)^{98}$。

9. 求函数 $y = (x^3 - 7)^{50}$ 在 $x = 2$ 处的切线方程（提示：先求导数和切点）。
   - 答案：导数 $y' = 50(x^3 - 7)^{49} \cdot 3x^2$，$x = 2$ 时 $y' = 600$，切点 $(2, 1)$，切线方程 $y - 1 = 600(x - 2)$。

### 理解应用

10. 为什么 $\frac{dy}{dx}$ 不是普通分数？
    - 答案：它是 $\frac{\Delta y}{\Delta x}$ 当 $\Delta x \to 0$ 时的极限，$dy$ 和 $dx$ 单独没有独立意义。

11. 介值定理和 EVT 都要求“闭区间 + 连续”，为什么缺一不可？
    - 答案：开区间可能无限接近端点但达不到；不连续可能跳过中间值或最值。

12. 自由落体中位置公式 $x = -\frac{1}{2}gt^2 + ut + h$ 里的 $\frac{1}{2}$ 从何而来？
    - 答案：速度从初速度 $u$ 均匀减小到 $u - gt$，平均速度为 $u - \frac{1}{2}gt$，乘以时间得到位移；或速度-时间图像面积。
