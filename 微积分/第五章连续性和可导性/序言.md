# 第五章：连续性和可导性 — 复习思维导图

---

## 一、本章核心目标

> **这一章本质上是在解决什么问题？**
>
> 给函数的"品质"分级——从"有定义"到"连续（不断笔）"再到"可导（光滑）"，层层递进。并研究连续性带来的两个强大工具：**介值定理**和**最大值最小值定理**。

**为什么学？**
- 连续性是极限的第一个重要应用
- 可导性是微积分的核心，后续一切（微分、积分、优化）都建立在它之上
- 搞清"连续"与"可导"的精确关系，避免后续学习中的概念混淆

---

## 二、关键知识地图

### 5.1 连续性（"不断笔"）

**在一点处连续**
- 定义：$\lim_{x \to a} f(x) = f(a)$
  - ① $f(a)$ 有定义
  - ② $\lim_{x \to a} f(x)$ 存在
  - ③ 两者相等

**在区间上连续**
- 开区间 $(a,b)$：每一点都连续
- 闭区间 $[a,b]$：开区间内连续 + 端点单侧连续

**介值定理（IVT）**
- 前提：闭区间 + 连续 + $f(a)f(b) < 0$
- 结论：存在 $c \in (a,b)$，$f(c) = 0$
- 应用：奇数次多项式必有根、证明方程有解

**最大值最小值定理（EVT）**
- 前提：闭区间 + 连续
- 结论：必有最大值和最小值

### 5.2 可导性（"光滑"）

**导数的直觉**
- 瞬时变化率（速度表读数）
- 切线斜率

**导数的定义**
- $f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$

**导函数**
- $f'(x)$ 是一个函数（每一点的导数）
- $f'(a)$ 是一个数（某一点的导数）

**导数不存在的场景**
- 尖点（$|x|$ 在 $x=0$）
- 不连续的点
- 垂直切线（斜率无穷大）

**左导数与右导数**
- 左导数 = 右导数（且有限）$\Leftrightarrow$ 可导
- 不等 $\rightarrow$ 不可导

**可导与连续的关系**
- 可导 $\Rightarrow$ 连续（强推弱）
- 连续 $\nRightarrow$ 可导（$|x|$ 是反例）

## 三、重点概念精讲

### 概念1：连续性

| 维度 | 内容 |
|:---|:---|
| **定义** | $\lim_{x \to a} f(x) = f(a)$ |
| **本质** | 函数在该点"没有断开"，图像可以一笔画出 |
| **三个条件** | ① $f(a)$ 有定义 ② 极限存在 ③ 两者相等 |
| **生活案例** | 汽车平稳行驶（速度连续变化），不会瞬间从 60km/h 跳到 0 |
| **常见错误** | 有定义 ≠ 连续（如分段函数在分界点） |
| **一句话记忆** | "极限值 = 函数值" |

### 概念2：介值定理（IVT）

| 维度 | 内容 |
|:---|:---|
| **定义** | 连续函数从负到正，必然经过零 |
| **本质** | 连续函数不会"跳过"中间值 |
| **前提** | 闭区间 $[a,b]$ + 连续 + $f(a)f(b) < 0$ |
| **结论** | 存在 $c \in (a,b)$，使 $f(c) = 0$ |
| **生活案例** | 温度从 10°C 升到 20°C，必然经过 15°C |
| **常见错误** | IVT 只能证明"存在性"，不能给出具体位置或个数 |
| **一句话记忆** | "不漏中间值" |

### 概念3：最大值最小值定理（EVT）

| 维度 | 内容 |
|:---|:---|
| **定义** | 闭区间上的连续函数必有最值 |
| **本质** | "有头有尾"（闭区间）+ "连绵不断"（连续）= 必有最高点和最低点 |
| **前提** | 闭区间 $[a,b]$ + 连续 |
| **结论** | 存在最大值和最小值（只保证存在性，不保证唯一性） |
| **常见错误** | 开区间上的连续函数"可能有最值，也可能没有" |
| **一句话记忆** | "闭区间 + 连续 = 必有最值" |

### 概念4：导数

| 维度 | 内容 |
|:---|:---|
| **定义** | $f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$ |
| **本质** | 瞬时变化率（速度表读数） |
| **几何意义** | 切线斜率 |
| **记法** | $f'(x)$、$y'$、$\frac{dy}{dx}$、$\frac{d}{dx}f(x)$ |
| **生活案例** | 汽车仪表盘上的"此刻速度" |
| **常见错误** | $\frac{dy}{dx}$ 不是分数，是极限的记法 |
| **一句话记忆** | "变化的快慢" |

### 概念5：可导与连续

| 维度 | 内容 |
|:---|:---|
| **核心关系** | 可导 $\Rightarrow$ 连续，连续 $\not\Rightarrow$ 可导 |
| **本质** | 可导比连续要求更严格：不仅不能断，还不能有尖角 |
| **反例** | $f(x) = |x|$ 在 $x=0$ 处连续但不可导（尖点） |
| **证明技巧** | 构造 $\frac{f(x+h)-f(x)}{h} \times h$ 来证明"可导必连续" |
| **一句话记忆** | "跑得顺畅（可导）⇒ 没停下来（连续），但反过来不成立" |

## 四、最容易混淆内容对比

### 对比1：连续 vs 可导

| | 连续 | 可导 |
|:---|:---|:---|
| **直观** | 图像不断笔 | 图像光滑无尖角 |
| **定义** | $\lim_{x \to a} f(x) = f(a)$ | $\lim_{h \to 0} \frac{f(a+h)-f(a)}{h}$ 存在 |
| **要求** | 低 | 高 |
| **关系** | 可导 ⇒ 连续 | 连续 ⇏ 可导 |
| **反例** | — | $|x|$ 在 $x=0$ |
| **一句话** | "一笔画出" | "没有尖角" |

### 对比2：$f'(x)$ vs $f'(a)$

| | $f'(x)$ | $f'(a)$ |
|:---|:---|:---|
| **是什么** | 函数 | 数值 |
| **输入** | 任意 $x$ | 固定点 $a$ |
| **输出** | 该点的瞬时变化率 | 该点的瞬时变化率 |
| **类比** | 速度公式 | 此刻速度表读数 |

### 对比3：IVT vs EVT

| | 介值定理（IVT） | 最大值最小值定理（EVT） |
|:---|:---|:---|
| **前提** | 闭区间 + 连续 + 端点异号 | 闭区间 + 连续 |
| **结论** | 存在 $c$ 使 $f(c) = 0$ | 存在最大值和最小值 |
| **本质** | 不漏中间值 | 必有最值 |
| **能否找精确值** | 否（只能证明存在） | 否（只知道存在） |

## 五、章节重点公式 / 定理整理

| 公式/定理 | 表达式 | 使用条件 | 常见题型 | 易错点 |
|:---|:---|:---|:---|:---|
| **连续性定义** | $\lim_{x \to a} f(x) = f(a)$ | 逐点判断 | 分段函数分界点 | 忽略"两者相等" |
| **介值定理** | $f(a) < 0 < f(b)$ 或 $f(a) > 0 > f(b)$ | 闭区间 + 连续 | 证明方程有根 | 只证明存在性 |
| **EVT** | 闭区间上连续 ⇒ 有最值 | 闭区间 + 连续 | 判断最值是否存在 | 开区间不适用 |
| **导数定义** | $f'(x) = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h}$ | 用极限求导 | 基本函数求导 | $h$ 不能提前为 0 |
| **可导条件** | $f'_-(a) = f'_+(a)$（有限） | 左右导数相等 | 分段函数可导性 | 不连续一定不可导 |
| **可导必连续** | 可导 $\Rightarrow$ 连续 | — | 判断题 | 逆命题不成立 |

## 六、导数不存在的情况（必记）

| 情况 | 例子 | 图像特征 |
|:---|:---|:---|
| **尖点** | $|x|$ 在 $x=0$ | V 字形，左右斜率不等 |
| **不连续** | 跳跃间断点 | 图像断开 |
| **垂直切线** | $\sqrt[3]{x}$ 在 $x=0$ | 切线垂直，斜率无穷大 |

## 八、知识链路

| 前置知识 | → | 当前知识 | → | 后续用途 |
|:---|:---|:---|:---|:---|
| 函数（输入→输出） | → | 连续性（不断笔） | → | 积分（求面积） |
| 极限（无限接近） | → | 可导性（瞬时变化率） | → | 微分（线性近似） |
| | | | → | 优化（求最值） |
| | | | → | 微分方程 |

**核心递进关系**：
- 有定义 → 连续 → 可导（要求越来越严格）
- 可导 $\Rightarrow$ 连续 $\Rightarrow$ 有定义（强推弱）

## 九、终极总结

> **第五章本质上是在解决什么问题？**
>
> 函数的"品质分级"问题——从"有定义"到"连续（不断笔）"再到"可导（光滑）"，层层递进。以及连续性带来的两个强大工具：**介值定理**（不漏中间值）和**最大值最小值定理**（必有最值）。
>
> **记住这张图**：
> - 可导函数 $\subset$ 连续函数 $\subset$ 有定义函数
> - $|x|$ 在 $x=0$：连续但不可导（尖点）
> - $1/x$ 在 $x=0$：不连续（断开）
