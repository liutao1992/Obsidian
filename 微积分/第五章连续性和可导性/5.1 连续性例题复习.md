## 一、提出问题

连续性题目花样很多：判断连续、补值使连续、分段函数、绝对值函数、$\dfrac{0}{0}$ 型极限……

但不管题目怎么变，核心都依据同一个定义：

$$
\lim_{x \to a} f(x) = f(a)
$$

判断连续，本质上就是检查一句话：

> **极限值 = 函数值**

---

## 二、建立概念：连续的本质

### 1. 连续的定义

函数 $f$ 在 $x = a$ 处连续，当且仅当：

$$
\lim_{x \to a} f(x) = f(a)
$$

也就是说，函数在该点的**趋势值**必须等于**实际值**。

### 2. 三种不连续类型

| 类型 | 原因 | 对应间断点 |
|------|------|------------|
| **没定义** | $f(a)$ 不存在 | 可去间断点 |
| **极限不存在** | 左右极限不一致 | 跳跃间断点 |
| **对不上**（最常考） | 极限存在但 $\neq f(a)$ | 可去间断点 |

---

## 三、题型一：判断是否连续

### 做题模板

```txt
判断 f 在 x = a 处是否连续：
1. 求函数值 f(a)
2. 求极限 lim_{x→a} f(x)
3. 比较两者是否相等
   相等 → 连续
   不相等 → 不连续
```

### 例题 1

$$f(x) = x^2 \ (x \neq 1), \quad f(1) = 2$$

判断 $f$ 在 $x = 1$ 处是否连续。

**步骤**：

1. 函数值：$f(1) = 2$
2. 极限：$\displaystyle\lim_{x \to 1} x^2 = 1$
3. 比较：$1 \neq 2$

**结论**：**不连续**（可去间断点）。

> 理解：函数的趋势是 $1$，但实际函数值是 $2$——点放错了位置。

### 例题 2（对比）

$$f(x) = x^2 \ (x \neq 1), \quad f(1) = 1$$

**步骤**：

1. 函数值：$f(1) = 1$
2. 极限：$\displaystyle\lim_{x \to 1} x^2 = 1$
3. 比较：$1 = 1$

**结论**：**连续**。

### 对比总结

| 情况 | 极限 | 函数值 | 结果 |
|------|------|--------|------|
| $f(1) = 2$ | $1$ | $2$ | 不连续 |
| $f(1) = 1$ | $1$ | $1$ | 连续 |

## 四、题型二：补值使连续

### 核心思路

> **补点 = 极限值**。要让分段函数在分界点连续，就令 $k$ 等于该点的极限值。

### 例题 3（经典模型）

$$f(x) = \frac{x^2 - 4}{x - 2} \ (x \neq 2), \quad f(2) = k$$

问：$k$ 取何值时，$f$ 在 $x = 2$ 处连续？

**步骤**：

1. 因式分解：$x^2 - 4 = (x - 2)(x + 2)$
2. 化简：$\dfrac{x^2 - 4}{x - 2} = x + 2$（$x \neq 2$）
3. 求极限：$\displaystyle\lim_{x \to 2} (x + 2) = 4$
4. 连续条件：$k = 4$

**结论**：$k = 4$ 时，$f$ 在 $x = 2$ 处连续。

### 例题 4（同类强化）

$$f(x) = \frac{x^2 - 9}{x - 3} \ (x \neq 3), \quad f(3) = k$$

**步骤**：

- 化简：$\dfrac{x^2 - 9}{x - 3} = x + 3$（$x \neq 3$）
- 极限：$\displaystyle\lim_{x \to 3} (x + 3) = 6$

**结论**：$k = 6$。

### 例题 5（三角函数）

$$f(x) = \frac{\sin x}{x} \ (x \neq 0), \quad f(0) = k$$

**关键知识**：$\displaystyle\lim_{x \to 0} \frac{\sin x}{x} = 1$（重要极限）

**结论**：$k = 1$。

## 五、题型三：分段函数在分界点的左右极限

当分段函数在分界点左右用**不同规则**时，必须分别算左极限和右极限。

### 核心口诀

> **先看左右，再谈极限。**

如果左右极限不相等，**极限根本不存在**——这时候不能说"极限值是多少"。

### 例题 7

$$f(x) = x + 1 \ (x < 0), \quad f(x) = x^2 \ (x \ge 0)$$

判断 $f$ 在 $x = 0$ 处是否连续。

**步骤**：

1. 函数值：$x = 0$ 属于 $x \ge 0$，所以 $f(0) = 0^2 = 0$
2. 左极限：$x \to 0^-$ 时用 $x + 1$，所以 $\displaystyle\lim_{x \to 0^-} f(x) = 0 + 1 = 1$
3. 右极限：$x \to 0^+$ 时用 $x^2$，所以 $\displaystyle\lim_{x \to 0^+} f(x) = 0$
4. 比较：左极限 $= 1 \neq 0 =$ 右极限

**结论**：左右极限不相等 $\Rightarrow$ **极限不存在** $\Rightarrow$ **不连续**（跳跃间断点）。

> 常见错误：直接说"极限值是 $1$"或"极限值是 $0$"——左右不一致时，根本不存在"一个极限值"。

### 例题 8（验证理解）

$$f(x) = 2x \ (x < 1), \quad f(x) = x + 1 \ (x \ge 1)$$

判断 $f$ 在 $x = 1$ 处是否连续。

**步骤**：

1. 函数值：$f(1) = 1 + 1 = 2$
2. 左极限：$\displaystyle\lim_{x \to 1^-} 2x = 2$
3. 右极限：$\displaystyle\lim_{x \to 1^+} (x + 1) = 2$
4. 比较：$2 = 2 = 2$

**结论**：左极限 = 右极限 = 函数值 $\Rightarrow$ **连续**。

### 分段函数在分界点的标准三步

对于 $f(x) = A(x) \ (x < a)$，$f(x) = B(x) \ (x \ge a)$，在 $x = a$ 处必须做三步：

1. **左极限**：用 $A(x)$ 算 $\displaystyle\lim_{x \to a^-} f(x)$
2. **右极限**：用 $B(x)$ 算 $\displaystyle\lim_{x \to a^+} f(x)$
3. **函数值**：$f(a) = B(a)$（因为 $x = a$ 归右边）

只有左极限 = 右极限 = 函数值，三者全相等，函数才连续。

## 六、题型四：绝对值函数的左右极限

绝对值 $|x|$ 本质是分段函数，遇到含绝对值的极限必须拆开讨论。

$$
|x| = x \ (x \ge 0), \quad |x| = -x \ (x < 0)$$

### 例题 9

$$\lim_{x \to 0} \frac{|x|}{x}$$

**拆开**：

- $x > 0$ 时：$\dfrac{|x|}{x} = \dfrac{x}{x} = 1$
- $x < 0$ 时：$\dfrac{|x|}{x} = \dfrac{-x}{x} = -1$

**求极限**：

- 左极限：$\displaystyle\lim_{x \to 0^-} \frac{|x|}{x} = -1$
- 右极限：$\displaystyle\lim_{x \to 0^+} \frac{|x|}{x} = 1$

**结论**：左极限 $\neq$ 右极限 $\Rightarrow$ **极限不存在**。

> 核心口诀：**只要左右极限不一样，极限一定不存在。**
>
> 常见错误：看到分子分母都趋近 $0$，就直接说"等于 $1$"——这里不是算数，是在看趋近过程。

## 七、题型五：$\dfrac{0}{0}$ 型极限

### 例题 10

$$\lim_{x \to 1} \frac{x^2 - 1}{x - 1}$$

直接代入 $x = 1$ 会得到 $\dfrac{0}{0}$，这是不定式，不能直接得出答案。

**步骤**：

1. 因式分解：$x^2 - 1 = (x + 1)(x - 1)$
2. 化简：$\dfrac{x^2 - 1}{x - 1} = x + 1$（$x \neq 1$）
3. 求极限：$\displaystyle\lim_{x \to 1} (x + 1) = 2$

**结论**：极限存在，等于 $2$。

> 注意：原函数在 $x = 1$ 处无定义（分母为零），所以这里算的是极限值，不是函数值。如果要让函数在 $x = 1$ 处连续，需要定义 $f(1) = 2$。

## 八、终极做题模板

遇到所有连续性题，统一流程：

```txt
1. 看函数值：f(a) = ?

2. 算极限：
   - 如果 a 两侧用同一规则 → 直接算双侧极限
   - 如果 a 两侧用不同规则 → 分别算左极限和右极限

3. 比较：
   - 左极限 ≠ 右极限 → 极限不存在，不连续（跳跃间断点）
   - 左极限 = 右极限 ≠ f(a) → 极限存在但不对，不连续（可去间断点）
   - 左极限 = 右极限 = f(a) → 连续
```

---

## 九、一句话总结

> **连续性的本质就是：函数的"趋势值"和"实际值"完全一致。**
>
> 分段函数在分界点，左趋势和右趋势也必须一致。

## 自测题

1. $f(x) = x + 3 \ (x \neq 2)$，$f(2) = 5$，判断 $x = 2$ 处是否连续。
2. $f(x) = \dfrac{x^2 - 16}{x - 4} \ (x \neq 4)$，$f(4) = k$，求使函数连续的 $k$。
3. $f(x) = x - 1 \ (x < 0)$，$f(x) = x + 1 \ (x \ge 0)$，判断 $x = 0$ 处是否连续。
4. 求 $\displaystyle\lim_{x \to 0} \frac{|2x|}{x}$。
5. 求 $\displaystyle\lim_{x \to 2} \frac{x^2 - 4}{x - 2}$。

> [!faq]- 点击查看答案
> 1. **连续**。$\lim_{x \to 2} f(x) = \lim_{x \to 2}(x+3) = 5$，且 $f(2)=5$，两者相等。
> 2. $k = 8$。$\dfrac{x^2-16}{x-4}=x+4$，极限为 $8$。
> 3. 不连续。左极限 $= -1$，右极限 $= 1$，左右不相等。
> 4. 极限不存在。$x>0$ 时为 $2$，$x<0$ 时为 $-2$。
> 5. $4$。$\dfrac{x^2-4}{x-2}=x+2$，极限为 $4$。
