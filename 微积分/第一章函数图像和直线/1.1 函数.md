## 基本概念

### 定义
把一个对象转化成另一个对象的规则，包含**定义域**、**转换规则**和**上域或值域**三部分。

### 函数本质
- 函数是**转换规则**
- $f$ 是函数，$f(x)$ 带自变量
- 说 $f(x)$ 是函数不太贴切

### 判断函数相同
定义域和对应规则都要相同。
- 例如：$y=x$ 与 $y=\frac{x^2}{x}$ 定义域不同，不是同一函数

### 生活化例子
- 动物腿的数量对应
- 宠物呕吐物颜色对应

**核心要求**：每个有效输入指定唯一输出，即一个 $x$ 只能对应一个 $y$

## 上域与值域

### 基本定义

| 概念 | 定义 | 类比 |
|------|------|------|
| 上域 (Codomain) | 函数"宣布"可能输出的所有值 | 超市声称"全场商品不超过100元" |
| 值域 (Range) | 函数实际输出的所有值 | 实际上有些商品就是100元 |

### 具体例子

$$f(x) = x^2, \quad \text{上域} = \mathbb{R}$$

```
上域 = ℝ = { ..., -3, -2, -1, 0, 1, 2, 3, ... }  ← 承诺"可能输出这些"
值域 = [0, +∞) = { 0, 1, 4, 9, 16, ... }          ← 实际只输出这些
```

### 为什么设计这两个概念？

#### 1. 先有价值域，后有上域

数学家研究函数时，总要问"输出结果是什么范围"，于是定义了**值域**。
但很快遇到问题：有些函数的值域**很难精确写出来**。

举例：$f(x) = x^2 - 2x + \sin(x)$

- 值域是什么？很难写出精确表达式
- 但你知道输出**肯定是实数**

于是发明**上域**：只说"输出是实数"，不用精确描述值域。

#### 2. 上域是"安全边界"

| 场景 | 没有上域 | 有上域 |
|------|----------|--------|
| 简单函数 | 说"值域是 $[0, +\infty)$" | 也可以说"上域是 $\mathbb{R}$" |
| 复杂函数 | 很难精确描述值域 | 说"上域是 $\mathbb{R}$"就够了 |
| 定义反函数 | 需要完整描述值域边界 | 可以用上域来界定范围 |

#### 3. 集合论需要

在抽象数学中，函数被定义为：

$$f: A \rightarrow B$$

- $A$ 是定义域
- $B$ 是上域（必须明确声明）
- 值域是 $B$ 的子集（实际输出）

**为什么必须声明 $B$？** 保证"每个输入都有输出，而且输出在 $B$ 里面"。

### 生活类比

```
没有上域  超市说"我们有各种商品"（不知道具体有什么）
有上域    超市说"我们有家电区"（上域 = 家电）
          实际只有冰箱和洗衣机（值域 = {冰箱, 洗衣机}）
          你至少知道：不会买到汽车（超出上域）
```

### 一句话总结

> **上域是"盒子外面的标签"，值域是"盒子里面实际装的东西"**
>
> - 上域是"安全边界"，值域是"实际活动范围"
> - 上域让数学描述更简洁
> - 上域让函数定义更严格（保证输出不会跑出预期范围）

## 区间表示

| 类型 | 符号 | 含义 |
|------|------|------|
| 闭区间 | $[a, b]$ | $a \leq x \leq b$，端点都能取到 |
| 开区间 | $(a, b)$ | $a < x < b$，端点不能取到 |
| 半开半闭 | $[a, b)$ | $a \leq x < b$ |
| 半开半闭 | $(a, b]$ | $a < x \leq b$ |
| 无穷 | $(a, +\infty)$ | $x > a$ |
| 无穷 | $(-\infty, b)$ | $x < b$ |
| 无穷 | $(-\infty, +\infty)$ | 全体实数 |

> **注意**：区间不用大括号，大括号一般表示集合

## 求定义域

### 常见要求
- **分母**：不能为 0
- **偶次根号**（二次方根、四次方根等）：被开方数 $\geq 0$
- **奇次根号**（立方根、五次方根等）：$x$ 取值随意
- **对数**：真数 $> 0$
- **tan 函数**：$\cos \neq 0$，不能等于 $\pm 90^\circ$ 等

### 综合题目
分别求出各部分要求，再取交集，最后写成区间形式。

## 用图像求值域

通过观察函数图像中 $y$ 能走过的区域来确定值域。

**举例**：
- $y=x^2$，$x \in [-2, 1]$，值域是 $[0, 4]$
- $y=2x$，$x \in (2, 4)$，值域是 $(4, 8)$

## 检验方法

### 垂线检验法
- **依据**：一个 $x$ 有唯一的 $y$ 与之对应；一个 $x$ 对应多个 $y$ 不允许；多个 $x$ 对应一个 $y$ 允许
- **应用**：判断图像是否为函数图像
- **举例**：
  - 圆不是函数图像（垂直 $x$ 轴画垂线与圆有两个交点）
  - 抛物线是函数图像（画垂线任何时候与它只有一个交点）

![垂线检验法](./imgs/vertical_line_test.png)

### 水平线检验法
- **用途**：判断函数是否有反函数
- **原理**：若多个 $x$ 对应一个 $y$，则不存在反函数（反函数会变成一个 $x$ 对应多个 $y$）

![水平线检验法](./imgs/horizontal_line_test.png)
